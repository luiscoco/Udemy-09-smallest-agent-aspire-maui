# Asset provenance

The astronaut image in src/SmallestAgent.Shared/wwwroot is the known local course asset, copied only from edition 04's specific public image. Original course reference: https://github.com/luiscoco/Udemy-Claude-Agent-SDK-lesson01-app at commit 832439954c11d4f3623d1b4a311f7dd67389fcc8. Retain upstream rights/attribution when redistributing. No real environment file was copied.

Shared pastel CSS and the local SVG/PlantUML templates were adapted from the earlier C# edition. This edition's generator extracts actual shared-client, Web API and SDK source; the AppHost excerpt explains its control-plane role separately. Markdig and HtmlSanitizer render safe Markdown; C# token coloring encodes code before adding spans. No hosted UML renderer is required.

Native icons, splash and platform scaffold are generated by the installed Microsoft MAUI Blazor Hybrid template. They are not downloaded third-party branding. The native app and browser companion use the same Razor class library/static assets.
